### 1.0.6 표 보기·주석 작성창 개선

- PDF 글자의 위치에서 반복되는 행·열을 인식해 좌우 넘김과 웹소설 스크롤 보기에서 **표**로 표시합니다. 앞뒤 본문은 문단으로 유지하며 표 안에서도 검색·링크·주석을 사용할 수 있습니다. 넓은 표는 표 영역 안에서 가로로 스크롤합니다. 표를 터치하거나 가로로 밀어도 책 페이지가 넘어가지 않습니다.
- 표 자동 인식은 정렬된 텍스트형 표를 대상으로 합니다. 이미지형 표·복잡한 병합 셀·불규칙한 배치는 정확히 복원되지 않을 수 있으므로 **PDF 원본** 보기로 확인하세요. 스캔 페이지는 계속 원본으로 표시합니다.
- ‘원본 상단/하단 가리기’와 ‘상단·하단바 기본 표시’ 설정을 삭제했습니다. 과거에 저장한 값도 더 이상 적용하지 않습니다. 도구는 읽기 화면 중앙을 터치해 표시하거나 숨길 수 있으며 텍스트형 여백 쪽수의 자동 숨김은 유지됩니다.
- 상단 주석 버튼이나 본문의 저장된 주석을 누르면 **주석 목록만** 열립니다. 키보드는 문장을 선택해 새 주석을 작성하거나 ‘수정’을 눌렀을 때 열립니다. 작성 패널은 키보드 위의 사용 가능한 화면에 맞춰 올라오며 저장·취소 시 키보드를 닫습니다. Android 15 이상에서는 키보드 높이를 네이티브 WebView 여백에도 반영합니다.
- 하단 페이지 슬라이더 오른쪽에 **현재 페이지 / 전체 페이지**를 표시합니다. 숫자는 원본 PDF의 페이지 기준이며 스크롤·슬라이더 이동 시 갱신됩니다.

**업데이트:** 위 1.0.6 서명용 ZIP을 Android Studio에서 열고 **Choose existing**으로 이전 `.jks` 키를 선택해 릴리스 APK를 만드세요. 앱 ID는 유지하고 versionCode는 6으로 올렸습니다. `yeobaek-1.0.6.apk`는 개발용 디버그 서명 파일이며 기존 릴리스 앱의 업데이트에는 사용할 수 없습니다. 상단 APK 다운로드는 사용자가 서명해 올린 기존 파일을 보존합니다.

검증: 단위 테스트 26개, 브라우저 기능 테스트 17개, 웹 빌드, Android debug/release 빌드 및 lint를 실행했습니다. 키보드 처리는 화면 축소와 visualViewport 축소를 모사해 검증했으며 실제 안드로이드 기기에서의 키보드·설치 검증은 아직 수행하지 못했습니다.

### 1.0.5 웹소설처럼 이어지는 스크롤

**읽기 설정 → 스크롤 + 웹소설 텍스트**를 선택하세요. PDF 페이지별 최소 높이와 여백을 없애고 본문을 하나로 이어 보여줍니다. 인쇄용 줄바꿈은 같은 문단 안에서 연결하며 페이지 중간에서 끊긴 문장도 다음 페이지의 텍스트와 이어집니다. 문장 끝·대화·들여쓰기·줄 간격·장 제목을 이용해 문단을 추정합니다. 영어의 소프트 하이픈과 일부 한국어 어미 분리도 처리합니다. PDF의 읽기 순서나 복잡한 다단 레이아웃 때문에 문단/띄어쓰기 추정이 원문과 다를 수 있으며 원본 PDF 파일은 변경하지 않습니다.

페이지 출처는 보이지 않는 앵커로 유지하므로 페이지 슬라이더·목차·북마크·읽던 PDF 페이지 복원이 계속 동작합니다. 페이지 경계를 가로지르는 구절을 검색하거나 주석으로 선택할 수도 있으며, 새 주석은 좌우 넘김 모드로 돌아가도 해당 부분에 표시됩니다. 기존 주석도 보존합니다. 좌우 넘김 모드와 PDF 원본 보기의 페이지 구분은 유지됩니다. 이미지형 스캔 페이지는 OCR 없이 원본으로 표시하므로 텍스트처럼 이어 붙이지 않습니다.

**이전 버전 업데이트:** 1.0.5 서명용 ZIP을 Android Studio에서 열고 **Choose existing**으로 이전 `.jks` 키를 선택해 서명하세요. 앱 ID는 유지하고 versionCode는 5로 올렸습니다. 기존 키로 서명한 APK로 업데이트하면 책장·북마크·주석을 유지할 수 있습니다. `yeobaek-1.0.5.apk`는 개발용 디버그 서명 파일이므로 기존 릴리스 앱의 업데이트에 사용하지 마세요. 상단 직접 다운로드는 사용자가 서명해 올린 기존 APK를 보존합니다.

### 1.0.4 폴더 편집·드래그 정렬

- 책 아래의 **⋮⋮ 손잡이**를 마우스나 손가락으로 끌어 다른 책 위치에 놓으면 순서가 바뀌며 **직접 정렬**로 전환됩니다. 책장 전체와 각 폴더의 순서는 따로 저장합니다. 업로드 순서·제목 순서로 바꿔도 저장한 직접 정렬은 유지됩니다.
- 폴더 목록 오른쪽 손잡이를 끌면 폴더 자체의 순서도 변경하고 저장할 수 있습니다. 키보드는 손잡이에 포커스를 두고 Space → 방향키 → Space로 이동하며 Escape로 취소합니다.
- 즐겨찾기는 항상 맨 위에 고정됩니다. 드래그로 순서를 바꿀 때도 즐겨찾기끼리, 일반 책끼리 이동합니다.
- 폴더를 연 뒤 **폴더 편집**을 누르면 기존 PDF를 체크해 추가하거나 체크를 해제해 제외할 수 있습니다. 다른 폴더의 PDF를 체크하면 그 폴더에서 현재 폴더로 이동합니다. 유지한 책의 직접 정렬은 보존하고 추가한 책은 뒤에 붙입니다.
- 폴더 안에서 **PDF 추가**로 새 파일을 선택하면 해당 폴더에 바로 들어갑니다. 개별 책의 `… → 폴더에서 제외`로 한 권만 뺄 수도 있습니다. 제외한 파일·읽던 위치·북마크·주석은 책장에 남습니다. 모든 책을 제외한 빈 폴더는 목록에서 사라집니다.
- 직접 정렬을 선택한 경우 ‘다른 책 펼치기’와 연속 읽기도 해당 폴더의 직접 정렬을 따릅니다. 변경 내용은 앱을 종료하고 다시 열어도 유지됩니다.

이전 1.0.4 빌드도 기존 `.jks` 키로 서명해 설치할 수 있습니다. 최신 버전은 위 1.0.6 안내를 참고하세요. 앱 ID는 유지하고 versionCode는 4로 올렸습니다. `yeobaek-1.0.4.apk`는 개발용 디버그 서명 파일이며, 기존 릴리스 앱의 업데이트에는 사용하지 마세요. 상단 APK 다운로드는 사용자가 서명해 올린 기존 파일을 보존합니다.

### 1.0.3 읽기 화면 개선

- 본문에 반복되던 제목·쪽수와 이전/다음 버튼을 제거했습니다. 제목은 도구 표시 시 상단에 크게, 굵게 표시됩니다. 하단 슬라이더로 직접 이동할 수 있습니다.
- 좌우 넘김 모드에서 왼쪽/오른쪽 25% 영역을 터치하면 페이지가 이동하고, 중앙 터치로 도구를 표시합니다. 스와이프도 지원합니다.
- PDF 여백의 텍스트형 쪽수를 찾아 텍스트 보기와 원본 보기에서 숨깁니다. 이미지형 쪽수는 설정의 ‘원본 상단/하단 가리기’로 0~15% 영역을 조절하세요. 비표준 위치의 쪽수는 자동 인식되지 않을 수 있습니다. 원본 파일은 수정하지 않습니다.
- PDF 내부 목차 링크와 별도 목차를 지원합니다. 내부 링크는 두 보기에서 해당 페이지로 이동하며 외부 링크는 http/https/mailto만 허용합니다.
- 문장을 길게 눌러 선택한 뒤 ‘선택한 문장에 주석’을 누르면 메모가 저장됩니다. 텍스트가 있는 원본 PDF에서도 선택할 수 있습니다. 주석 탭에서 수정·삭제·해당 페이지 이동이 가능합니다. 스캔 이미지에는 인용문을 직접 입력할 수 있습니다. 주석은 앱 저장소에 보관하고 PDF 파일에는 삽입하지 않습니다.
- 모든 하단 패널은 화면 절반 높이에서 시작합니다. 상단 손잡이를 위아래로 끌어 28~90%로 조절할 수 있으며 설정 변경은 열린 패널 위의 본문에 즉시 반영됩니다.
- 모바일 책장을 3열로 배치하고 간격을 넓혔습니다. 목록 보기에서는 긴 제목을 책 영역 안에서 줄바꿈하며 가로 넘침을 방지합니다.
- 묶음 책을 열면 다른 책 보기와 연속 읽기는 해당 폴더 안으로 제한됩니다. 묶음 없는 책에서 열면 다른 책 패널이 폴더별로 정리되어 표시됩니다. 각 폴더 안에서는 즐겨찾기 고정 및 선택한 정렬을 따릅니다.
- 연속 보기에서 스크롤 끝까지 읽거나 끝에서 위로 더 밀면 다음 책으로 이동합니다. 단순히 마지막 위치를 복원하거나 슬라이더로 이동한 것만으로는 책이 자동 전환되지 않습니다. 마지막 책에서는 종료 안내를 표시합니다.

**설치/업데이트:** 위 ‘APK 바로 다운로드’는 사용자가 서명해 올린 기존 1.0.2 파일입니다. 최신 기능은 위 1.0.6 안내를 참고하세요. 이전 1.0.3 빌드의 앱 ID도 동일하고 versionCode는 3입니다. 같은 키를 사용하면 기존 책장·주석을 유지하며 업데이트할 수 있습니다. ZIP에는 서명 키가 포함되지 않습니다. `yeobaek-1.0.3.apk`는 개발 검증용 디버그 서명 파일이므로 기존 릴리스 앱의 업데이트용으로 사용하지 마세요.

### Windows 11에서 터미널 없이 릴리스 서명하기

1. 위 서명용 ZIP 전체를 압축 해제합니다. 이 패키지에는 이미 빌드한 웹 화면과 안드로이드 네이티브 의존성이 들어 있어 npm 설치가 필요하지 않습니다.
2. Android Studio에서 **File → Open**을 누르고 압축을 푼 `PDF_VIEWER_M/android` 폴더를 엽니다. 부모 폴더를 열지 마세요.
3. Gradle 동기화를 기다립니다. 의존성 다운로드에 인터넷이 필요합니다. SDK 35와 Gradle JDK 21을 사용합니다.
4. **Build → Generate Signed App Bundle or APK → APK**를 선택합니다.
5. 기존 앱을 업데이트할 때는 **Choose existing**으로 이전에 사용한 `.jks` 키를 선택하세요. 첫 배포일 때만 **Create new**로 키를 만듭니다. 키와 비밀번호를 GitHub나 채팅에 올리지 마세요.
6. **release**를 선택해 완료합니다. 생성된 APK는 Android Studio의 완료 안내에서 찾을 수 있습니다.

서명용 ZIP은 미서명 릴리스 빌드로 검증했습니다. 개인 키로 서명한 최종 APK와 실제 기기 설치 검증은 아직 완료하지 않았습니다. 상단 설치용 APK는 사용자가 올린 기존 서명 파일입니다. 서명용 ZIP에 포함된 최신 코드는 기존 키로 직접 서명해야 하며, 외부 설치 안내가 사라지는 것은 아닙니다.

### 1.0.1 보안 수정

PDF 엔진을 `pdfjs-dist 6.2.108`로 업데이트해 GHSA-hq66-cqwq-w95j 취약점을 수정했습니다. npm 보안 감사, 기존 기능 테스트, Android 빌드와 lint로 확인했습니다. 검사 결과는 실행 시점의 알려진 취약점에 대한 결과이며 Google의 안전 인증이 아닙니다.

모바일용 로컬 PDF 뷰어 **여백**입니다. 안드로이드에서는 APK를 설치해 서버 없이 실행할 수 있으며, 웹 버전도 제공합니다. PDF는 서버로 업로드하지 않고 앱 또는 브라우저의 IndexedDB에 저장합니다. 읽기 설정은 localStorage에 저장하며 PDF 처리 라이브러리와 워커도 앱에서 제공합니다. 사용 중 외부 API, 계정, 클라우드 저장소가 필요하지 않습니다.

## 안드로이드 APK 설치 (터미널 불필요)

`releases/yeobaek-1.0.2.apk`를 휴대폰에 다운로드하고 파일 앱에서 열어 설치하세요. 브라우저 또는 파일 앱에 ‘이 출처의 앱 설치 허용’이 필요할 수 있습니다. 설치 후 **여백** 아이콘을 누르고 **PDF 추가**로 휴대폰 파일을 선택하면 됩니다. 실행에는 PC, 개발 서버, 인터넷 연결이 필요하지 않습니다.

Android 8.0 이상과 Android System WebView 109 이상이 필요합니다. WebView가 오래된 경우 앱 안내에 따라 Play 스토어에서 Android System WebView/Chrome을 업데이트하세요. PDF 엔진은 호환성용 빌드를 사용합니다. 상태바·내비게이션바 영역을 피하고 안드로이드 뒤로가기 버튼은 설정 창 닫기 → 책장으로 돌아가기 → 앱 종료 순서로 동작합니다.

상단 다운로드 파일은 사용자가 릴리스 키로 서명해 올린 개인 배포용 APK입니다. 개발 스크립트로 생성하는 APK는 별도의 디버그 서명 빌드입니다. Play 스토어에 게시한 앱은 아닙니다. PDF·설정·북마크는 앱 내부 WebView 저장소에 남습니다. 웹 브라우저의 기존 책장은 자동으로 가져오지 않으므로 파일을 다시 추가하세요. 앱을 삭제하거나 앱 데이터를 지우면 책장도 삭제됩니다. 원본 PDF는 별도로 보관하세요.

APK 빌드 및 서명 검증과 웹 기능 자동 테스트를 수행했습니다. 이 환경에는 안드로이드 기기/에뮬레이터가 없어 실제 기기 설치·파일 선택·실행은 아직 검증하지 못했습니다.

### 개발자가 APK를 다시 빌드할 때

JDK 21, Android SDK (API 35 / Build Tools 34 이상), Node.js, Python 3이 필요합니다. 개발 기기에서는 `JAVA_HOME`과 `ANDROID_HOME`을 설정하세요. 준비된 클라우드 환경에서는 설치된 `/workspace/android-tools/jdk`와 `/workspace/android-sdk`를 자동으로 사용합니다.

```sh
npm ci
npm run android:apk
```

웹 빌드 → Capacitor 동기화 → 안드로이드 APK 빌드와 lint → `releases` 복사 및 SHA-256 생성 순서로 실행합니다. 서명 키는 저장소에 포함하지 않습니다. 개인용 APK를 업데이트할 때는 동일한 디버그 키를 유지해야 합니다. 배포용 릴리스는 별도 릴리스 서명 설정이 필요합니다.

## 웹 버전 개발 실행

Node.js 22.13 이상 또는 24 이상이 필요합니다. 이 환경에서는 Node.js 24로 검증했습니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 주소로 접속합니다. 휴대폰과 실행하는 컴퓨터가 같은 Wi-Fi에 있으면 컴퓨터의 LAN IP와 5173 포트로 접속할 수 있습니다. 방화벽에서 해당 포트의 로컬 네트워크 접근이 허용되어야 합니다. 휴대폰에서 localhost는 컴퓨터가 아니라 휴대폰 자체를 가리킵니다. 클라우드 환경에서 실행할 때에는 플랫폼이 제공하는 접속 경로가 있어야 합니다.

배포용 빌드를 로컬에서 실행하려면:

```sh
npm run build
npm run preview -- --port 4173
```

주소의 프로토콜·호스트·포트와 브라우저가 달라지면 별개의 책장입니다. 컴퓨터에서 추가한 PDF가 휴대폰으로 자동 동기화되지는 않습니다. 휴대폰 브라우저에서 파일을 직접 선택해 주세요. 브라우저 데이터를 지우거나 시크릿 모드를 종료하면 저장 내용이 없어질 수 있으므로 원본 PDF는 별도로 보관하세요. 서버가 켜져 있어야 앱에 새로 접속할 수 있습니다. 웹 버전의 서비스 워커 기반 오프라인 재접속과 OCR은 이번 버전에 포함하지 않았습니다. 안드로이드 APK는 서버 없이 실행할 수 있습니다.

## 사용

- **PDF 추가**: 여러 파일을 한 번에 선택하거나 책장에 끌어다 놓습니다. PDF 첫 페이지가 표지로 표시됩니다.
- **책 관리**: 책 아래의 `…`에서 제목과 시리즈를 바꾸거나 삭제합니다. 원본 PDF 파일명과 내용은 변경하지 않습니다.
- **시리즈**: 새 시리즈 만들기에서 이름과 책을 선택합니다. 왼쪽 메뉴 또는 모바일 상단에서 해당 시리즈만 볼 수 있습니다. 책 관리에서 시리즈 이름을 비우면 묶음이 해제됩니다.
- **정렬**: 업로드 순서(먼저 추가한 순서), 제목 순서, 드래그로 저장한 직접 정렬. 즐겨찾기는 항상 위에 고정되며 즐겨찾기 안에서도 선택한 정렬이 적용됩니다. 연속 보기는 묶음 책에서는 해당 폴더 안의 현재 정렬 순서를 따르고, 묶음 없는 책에서는 전체 책장의 정렬 순서를 따릅니다.
- **읽기**: 표지나 제목을 누르면 읽던 페이지를 엽니다. 좌우 넘김은 스와이프, 좌우 가장자리 터치, 키보드 좌우 방향키로 이동합니다. 스크롤 모드에서는 위아래로 읽습니다. 하단 가로 슬라이더로 원하는 PDF 페이지에 바로 이동합니다.
- **도구**: 본문 터치로 상·하단 도구를 숨기거나 표시합니다. 오른쪽 위의 검색, 북마크, 다른 PDF, 설정을 사용할 수 있습니다. 도구가 숨겨져도 상단 `…`로 다시 표시할 수 있습니다.
- **설정**: 명조/고딕/고정폭 글꼴, 글자 크기, 행간, 여백, 기본 도구 표시, 5가지 테마(화이트/다크/샌드/세이지/미스트), 들여쓰기, 연속 보기를 제공합니다. 글꼴은 기기에 설치된 시스템 글꼴을 사용합니다.
- **연속 보기**: 좌우 넘김 모드의 마지막 페이지에서 오른쪽을 터치하거나, 스크롤 모드에서 끝까지 내리면 정렬상 다음 PDF의 읽던 위치로 이동합니다. 마지막 책에서는 종료 안내가 표시됩니다.

## PDF 텍스트와 원본

웹소설 텍스트 보기는 PDF 텍스트를 추출합니다. 좌우 넘김 모드에서는 PDF 페이지 단위로 표시하고, 스크롤 모드에서는 페이지 경계와 인쇄용 줄바꿈을 이어 하나의 본문으로 표시합니다. 글꼴·크기·행간·들여쓰기는 텍스트 보기에만 적용됩니다. 원문 PDF가 다단 구성이나 복잡한 레이아웃이면 추출 순서와 줄바꿈이 다를 수 있습니다. 들여쓰기는 추출된 각 문단의 첫 줄에 적용됩니다. 변경한 글자 크기에 따라 한 PDF 페이지 안에서 세로 스크롤이 필요할 수 있으며, 화면 크기별 재페이지화는 하지 않습니다.

텍스트가 없는 스캔 페이지는 자동으로 원본을 표시하며 OCR과 본문 검색은 지원하지 않습니다. 언제든 설정에서 PDF 원본 보기로 전환할 수 있습니다. 원본 캔버스는 화면 주변 페이지만 렌더링해 메모리 사용을 줄입니다. 암호로 잠긴 PDF는 잠금을 해제한 뒤 추가해야 합니다.

## 검증

```sh
npm test
npm run build
CHROMIUM_PATH=/path/to/chromium npx playwright test
```

Playwright 설정은 기본적으로 `/usr/bin/chromium`을 사용합니다. 해당 경로가 없는 기기는 설치된 Chromium 경로를 `CHROMIUM_PATH`로 지정하세요. 브라우저 테스트는 합성 PDF로 모바일 업로드·즐겨찾기·이름 변경·시리즈·검색·북마크·테마·글자 크기·위치 복원·연속 보기·원본 렌더링·삭제와 데스크톱 레이아웃을 검증합니다.
